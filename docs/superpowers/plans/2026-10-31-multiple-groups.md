# 複数所属の実装計画

1. 既存98テストを確認し、所属追加による上書きを再現するテストを追加。
2. 所属エンティティ、追加・解除・判定、全リポジトリ読込、起動時の追加移行を実装。
3. 管理コマンド、申請判定・一覧、予算表示先選択、案内・表示を更新。
4. 単体テストと独立 PostgreSQL で移行・再起動・保存を検証。関連資料を更新。
5. コードレビューを受け、指摘を修正して再検証。コミット・push・PR作成。
6. 本番データをバックアップして更新し、所属・財務データ・証憑保持とコマンド登録を確認。
