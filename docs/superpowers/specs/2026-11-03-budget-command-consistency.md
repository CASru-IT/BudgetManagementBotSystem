# 予算コマンドの英語統一と入力候補

ユーザー指定: 英語のコマンド名に統一し、重複する予算履歴を統合。取消対象IDは既存コマンドと同じ入力候補で選択する。

- `/usage-history` と `/予算履歴` を `/budget-history` に統合。収入・支出・取消のすべてを表示する。既存のgroup-id省略、fiscal-year、ページングを維持する。
- `/予算取消` を `/cancel-budget transaction-id:<候補> reason:<理由>` に変更。既存の確認・認可・二重取消対策を維持する。
- 候補は有効なAdmin / President / Accountantだけに表示。対象外（支出・既知の返金・取消済・残高不足）は含めない。過年度も含め、ID・班・金額・日本時間の日付・年度で検索してから最新順の最大25件に絞る。旧収入は由来未確認と明示する。
- Discordで班名・日付などの文字検索を可能にするため、transaction-idは文字列の入力候補として登録する。候補の値は数字のID文字列で、確定したコマンド入力を正のintに検査・変換する。ID完全一致を最優先し、そのほかを最新順に表示する。
- 旧名は登録から外し、クライアントに残った旧コマンドを実行した場合は新名へ案内する。メニューと運用資料を更新する。
- DB変更なし。検証後、現在の本番版を基点にバックアップを取り本番へ反映する。

重複する別名を残す方式は用途の重複が解消しないため採用しない。`budget-history` は収入・支出を含む履歴であることを表す名称として採用。
